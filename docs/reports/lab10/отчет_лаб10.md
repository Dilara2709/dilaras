# ЛР10. Отчёт

## 1. Соответствие C# и SQL
| C# | SQL |
|---|---|
| Id | id |
| Title | title |
| CarriageId | carriage_id |
| CreatedAt | created_at |
| AssigneeUserId | assignee_user_id |

## 2. Пара LINQ / SQL
LINQ: `_db.Tickets.Where(t => t.Status == "New").OrderByDescending(t => t.CreatedAt).ToList()`
SQL: `SELECT * FROM trips WHERE status = 'New' ORDER BY created_at DESC;`

## 3. Рестарт-тест (главное)
1. Создала через Swagger: `POST /api/tickets`, получила `id = 1`, `number = TMP-...`, `title = «Москва — Владивосток»`, `status = New`.
2. **Ctrl+C**, остановила сервер.
3. `dotnet run` снова.
4. `GET /api/tickets/1` -> **та же поездка**, тот же номер, тот же статус.

## 4. PATCH сохраняются в БД
- PATCH /api/tickets/1/assignee { "assigneeUserId": 2 } -> 200
- PATCH /api/tickets/1/status { "status": "InProgress" } -> 200
- Перезапуск -> GET /api/tickets/1 -> status = "InProgress", assigneeUserId = 2

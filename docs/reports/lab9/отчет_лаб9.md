# Отчет по ЛР9

## 1. Схема данных
Созданы 3 таблицы: carriages (вагоны), users (пользователи), trips (поездки).
Есть внешние ключи (carriage_id, created_by_user_id) и CHECK на 4 статуса.

## 2. Данные (Seed)
Заполнено 4 поездки. Представлены все 4 статуса: New, InProgress, Closed, Cancelled.

## 3. Запросы
### 3.1. Фильтр и сортировка (WHERE, ORDER BY)
SELECT number, title, status, created_at FROM trips WHERE status = 'New' ORDER BY created_at DESC;

### 3.2. Соединение (JOIN)
SELECT t.number, t.title, c.name AS carriage_name, t.status FROM trips t JOIN carriages c ON c.id = t.carriage_id;

### 3.3. Агрегация (GROUP BY)
SELECT status, COUNT(*) AS count FROM trips GROUP BY status;

### 3.4. JOIN + LEFT JOIN
Запрос, выводящий создателя и исполнителя.

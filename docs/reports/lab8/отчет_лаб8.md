# Отчет по ЛР8

## 1. Создание (201)
POST /api/tickets
Тело: {"title": "Москва - Казань", "siteId": 2, "description": "Ночной поезд, ищу попутчиков"}
Результат: код 201, вернулись id, number (TMP-1), status (New).

## 2. Ошибка валидации (400)
POST /api/tickets с коротким title ("abc").
Результат: код 400, ошибка "Тема: от 5 до 80 символов".

## 3. Несуществующий ID (404)
GET /api/tickets/999999
Результат: код 404.

## 4. Конфликт статуса (409)
PATCH /api/tickets/2/status (status: "InProgress") без исполнителя.
Результат: код 409, "Нельзя перевести в InProgress без исполнителя".

## 5. Успешное назначение и смена статуса (200)
PATCH /api/tickets/2/assignee (assigneeUserId: 5) -> 200
PATCH /api/tickets/2/status (status: "InProgress") -> 200

## 6. Лог неожиданной ошибки (500)
Временно вызывала throw new Exception в TicketService.cs.
Клиент получил 500 без stack trace.
В терминале появилась строка: "CreateTicket failed; SiteId=2; error=Exception".

## 7. Коллекция запросов
Экспортирована и лежит в docs/api-collection/tickets.postman_collection.json.

# Архитектура

## Схема из трёх узлов

```text
Vue 3 + Vite                    ASP.NET Core                     PostgreSQL
localhost:5173  -------------> localhost:5000  -------------->  обычно :5432
                     HTTP                       запросы к БД
```

## Пояснение

- **Vue 3** (`localhost:5173`) — клиент. Рисует экраны: список финансовых операций, форму создания, карточку операции, отчёты по статьям бюджета. Отправляет HTTP-запросы к API.
- **ASP.NET Core** (`localhost:5000`) — сервер. Проверяет права ролей (бухгалтер, аналитик, финансовый директор), валидирует суммы и статусы, применяет правила планирования и анализа.
- **PostgreSQL** (обычно `:5432`) — хранилище. Хранит финансовые операции, статьи бюджета и пользователей.

## Стрелки

```text
Vue  ->  ASP.NET Core           пример: POST /api/operations
ASP.NET Core  ->  PostgreSQL            запросы к БД
```

## Почему браузер не лезет в PostgreSQL напрямую

Прямой стрелки от браузера к базе нет: иначе клиент получает доступ к данным и обходит серверные правила.

## Роли в системе

| Роль | Создаёт | Назначает | Меняет статус |
|---|---|---|---|
| Бухгалтер | да | да | нет |
| Аналитик | нет | нет | да (только свою) |
| Финансовый директор | нет | да | нет |

## 1. Название и организация

- **Название системы:** Разработка программного обеспечения для организации социального взаимодействия попутчиков в поездах дальнего следования.
- **Организация / подразделение:** учебная служба организации взаимодействия пассажиров поездов дальнего следования.
- **№ из таблицы примеров:** своя тема.

## 2. Главная сущность и справочник

- **Главный объект:** поездка (Trip).
- **Справочник:** тип вагона (Carriage).
- **Поле-ссылка в JSON:** carriageId.
- **Поле-ссылка в БД:** carriage_id.

Поездка содержит маршрут, описание, тип вагона, статус,
создателя и назначенного ответственного.

## 3. Роли и права

| Роль | Создаёт | Назначает | Меняет статус |
|---|---|---|---|
| Пассажир | да | нет | отменяет свою новую поездку |
| Проводник | нет | нет | да, только назначенную поездку |
| Админстратор | нет | да | нет |

Проводник не может назначать себя самостоятельно.

## 4. Сценарий в одно предложение

Пассажир создаёт поездку с указанием маршрута, типа вагона и описания → администратор назначает проводника → назначенный проводник переводит поездку New → InProgress → Closed.

Пассажир может отменить свою поездку в статусе New, переведя её в Cancelled.

## 6. Что не входит в семестр

1. Покупка и бронирование железнодорожных билетов.
2. Оплата поездок.
3. Интеграция с системой продажи билетов РЖД.
4. Мобильное приложение.
5. Онлайн-чат между пассажирами.
6. Автоматический подбор попутчиков.
7. SMS- и email-уведомления.

## 7. Запас под ВКР

### Данные и процессы

1. Подбор попутчиков по интересам.
2. Хранение истории изменения статусов поездок.

### Связь с другими системами

3. Интеграция с расписанием поездов.
4. Отправка уведомлений участникам поездки.

### Масштабирование

5. Добавление групповых обсуждений поездок.
6. Развитие системы рейтингов и отзывов о попутчиках.

## 8. Чем не копия соседа

- Предметная область: социальное взаимодействие пассажиров
  поездов дальнего следования.
- Главная сущность: поездка.
- Справочник: тип вагона.

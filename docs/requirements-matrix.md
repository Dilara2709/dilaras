
# Матрица требований

## Предметная область

Организация социального взаимодействия попутчиков
в поездах дальнего следования.

- Главная сущность — поездка (Trip).
- Справочник — тип вагона (Carriage).
- Поле-ссылка — carriageId.
- Основной путь API — /api/trips.

## Соответствие требований ЛР1

| Требование ЛР1 | Поле или сущность | Запрос | Критерий |
|---|---|---|---|
| ФТ-1. Создать поездку | Trip, title, carriageId, description | POST /api/trips | 1 |
| ФТ-2. Назначить проводника | assigneeUserId | PATCH /api/trips/{id}/assignee | 2 |
| ФТ-3. Перевести поездку в работу | status | PATCH /api/trips/{id}/status | 3 |

## Критерии приёмки

### Критерий 1. Создание поездки

Пассажир вводит маршрут, выбирает тип вагона
и заполняет описание.

После успешного создания поездка появляется
в списке со статусом New и человеческим номером.

### Критерий 2. Назначение ответственного

Администратор назначает проводника
на поездку в статусе New.

Поле assigneeUserId получает идентификатор
назначенного пользователя.

Статус поездки остаётся New.

### Критерий 3. Перевод поездки в работу

Назначенный проводник переводит
поездку из статуса New в InProgress.

Другой ответственный не может изменить статус
этой поездки.
